Real-time Inventory Streaming

An event-driven streaming layer that pushes live property inventory to enterprise client portals: Apache Kafka with per-entity ordering on the backend, WebSockets to the browser.

Role
Team Lead & architect
Company
Indus Real Estate
Year
2025
Stack
Kafka · Redis · WebSockets · Angular
<200msstreaming latency with ordered updates
10,000+daily active users on live portals
Pushchanges reach the browser as they happen

The problem

Property availability changes constantly, and clients and brokers act on what they see on screen. If the portal lags behind, they act on outdated inventory. The portals needed to reflect every change within moments, for thousands of users at once, and updates for the same property had to arrive in the right order.

Architecture

Key design decisions

Partition by entity key for ordering

Kafka only guarantees order within a partition. Keying every event by its property ID sends all updates for one property to the same partition, so they are processed in order, while different properties are spread across partitions and processed in parallel.

Push over WebSockets, not polling

Thousands of portals polling for changes would multiply load and still show stale data between polls. A WebSocket connection lets the server push each change the moment it happens.

Redis pub/sub for fan-out

Clients are spread across many WebSocket gateway instances. Publishing updates through Redis pub/sub means every gateway receives them and delivers to its own connected clients, so gateways scale horizontally without knowing about each other.

Outcome

Inventory updates reach portals in under 200ms with per-property ordering, for 10,000+ daily active users, removing the data delays users previously saw.

Happy to go deeper

Topics I enjoy discussing in a design interview about this system:

  • Choosing partition counts and handling hot keys
  • Consumer rebalancing without breaking ordering
  • Reconnection and catch-up when a WebSocket client drops
  • Back-pressure when a burst of updates arrives
